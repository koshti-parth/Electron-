This repository contains about electron setup.

Electron is framework which used to develop desktop application using web technologies such as HTML,CSS,JS ,React js and nodeJs as backend.

In electron You must know below things such as,

IPC (Inter Process Communication)
Ipcmain ,IpcRenderer
app - Manage app event's Lifecycle
BrowserWindow
Tray 
Menu
shell
Notification

In electron everything works on action.

For Database we will use Mongodb,nedb etc.
